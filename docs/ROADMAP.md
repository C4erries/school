# Roadmap

Общий план развития проекта. Каждая фаза — это self-contained milestone с рабочим результатом.

> **Статусы**: 🔲 Planned · 🔵 In Progress · ✅ Done · ⏸️ Paused

---

## Фаза 0: Фундамент 🔵
> **Цель**: рабочий скелет проекта, CI-ready, можно начинать писать фичи.

- 🔲 Структура Go-проекта (DDD layout)
- 🔲 Docker Compose: Postgres, Redis, MinIO, Nginx
- 🔲 Конфигурация через env (12-factor)
- 🔲 Миграции БД (выбрать инструмент, первая миграция)
- 🔲 HTTP сервер (chi/echo/gin — выбрать)
- 🔲 Логирование (slog / zerolog)
- 🔲 Healthcheck endpoint
- 🔲 Makefile / Taskfile с базовыми командами
- 🔲 Линтер (golangci-lint)
- 🔲 README с инструкцией запуска
- 🔲 React проект (Vite + TypeScript)
- 🔲 Nginx конфиг (proxy → backend, → frontend)

**Definition of Done**: `docker compose up` запускает всё, healthcheck отвечает 200, фронт показывает "Hello School".

---

## Фаза 1: Аутентификация и пользователи
> **Цель**: регистрация, логин, роли, базовый UI.

- 🔲 Модель User (email, password hash, role)
- 🔲 Регистрация / Логин (JWT + refresh token)
- 🔲 Middleware авторизации
- 🔲 RBAC: student, teacher, assistant, admin
- 🔲 API: CRUD пользователей (admin)
- 🔲 Фронт: страницы логина/регистрации
- 🔲 Фронт: защищённые роуты

**Definition of Done**: можно зарегаться, залогиниться, видеть разный контент по ролям.

---

## Фаза 2: Курсы и уроки
> **Цель**: CRUD курсов, модулей, уроков. Базовый просмотр.

- 🔲 Модели: Course, Module, Lesson
- 🔲 API: CRUD курсов (teacher/admin)
- 🔲 API: список курсов, детали курса (student)
- 🔲 Фронт: каталог курсов
- 🔲 Фронт: страница курса с модулями и уроками
- 🔲 Фронт: создание/редактирование курса (teacher)
- 🔲 Прогресс ученика (отметка "пройдено")

**Definition of Done**: преподаватель создаёт курс с уроками, ученик видит и проходит.

---

## Фаза 3: Видео-контент
> **Цель**: загрузка видео, хранение в MinIO, стриминг.

- 🔲 Upload API (multipart, presigned URLs)
- 🔲 Хранение в MinIO
- 🔲 Видеоплеер на фронте
- 🔲 Транскодинг (FFmpeg worker — опционально)
- 🔲 Привязка видео к урокам

**Definition of Done**: преподаватель загружает видео, ученик смотрит в браузере.

---

## Фаза 4: Задания и проверка
> **Цель**: ученики сдают задания, преподаватели проверяют.

- 🔲 Модели: Assignment, Submission, Review
- 🔲 Загрузка файлов/фото (задания)
- 🔲 Workflow: submitted → in_review → approved / revision_needed
- 🔲 Комментарии к заданиям
- 🔲 Уведомления о статусе
- 🔲 Фронт: сдача задания
- 🔲 Фронт: панель проверки (teacher/assistant)

**Definition of Done**: полный цикл сдачи-проверки задания работает.

---

## Фаза 5: Расписание и календарь
> **Цель**: планирование занятий, интеграция с Google Calendar.

- 🔲 Модель: Event (online/offline, time, location/link)
- 🔲 API: CRUD событий
- 🔲 Бронирование слотов
- 🔲 Интеграция Google Calendar API
- 🔲 Фронт: календарь (fullcalendar / custom)
- 🔲 Напоминания

**Definition of Done**: можно назначить встречу, она появляется в Google Calendar.

---

## Фаза 6: Финансы
> **Цель**: учёт оплат, начисления преподавателям.

- 🔲 Модели: Payment, Transaction, TeacherPayout
- 🔲 Учёт оплат за занятия / курсы
- 🔲 Баланс ученика / преподавателя
- 🔲 Интеграция с платёжной системой (Stripe / ЮKassa)
- 🔲 Фронт: история платежей
- 🔲 Фронт: панель финансов (admin)

**Definition of Done**: оплата проходит, деньги учитываются, преподаватель видит свой баланс.
