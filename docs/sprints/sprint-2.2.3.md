## 🎯 Цели спринта

1. **Редизайн Главного экрана (Командный центр репетитора / Control Center)**:
   - Единый агрегирующий эндпоинт `GET /api/v1/dashboard/summary` для исключения каскадных N+1 waterfall-запросов с фронтенда.
   - Виджет «Ближайшие уроки на сегодня» со ссылками на онлайн-звонки, кабинетами и быстрыми действиями.
   - Виджет «Финансовый срез текущего месяца» (Заработано факт, Ожидается прогноз, Дебиторская задолженность учеников).
   - Оперативные счетчики (запланировано часов на неделю, активные клиенты) и быстрые действия.
2. **Разделение Аналитики (Факт vs Прогноз) через Segmented Control ([ADR-009](../decisions/0009-analytics-forecast-and-tag-classification.md))**:
   - Вкладка «История (Факт)»: свершившиеся результаты (`status = completed`), графики динамики, форматы, рейтинг учеников.
   - Вкладка «Прогноз (План)»: эндпоинт `GET /api/v1/analytics/forecast`, расчет будущей нагрузки (часы) и ожидаемого валового/чистого дохода по запланированным занятиям (`status = scheduled`) и индивидуальным ставкам клиентов.
3. **Статистика учеников и доходности по тегам**:
   - Эндпоинт `GET /api/v1/analytics/tags`: группировка по всем тегам с подсчетом числа учеников, отработанных часов, валовой выручки и чистого дохода.
4. **Семантическая очистка Бухгалтерии от информационных тегов**:
   - Взаиморасчеты с партнерскими школами (`/finance/partner-settlements`) отфильтрованы строго по условию `school_percent > 0`. Информационные маркеры (0%) больше не создают пустых строк.
5. **Индикатор текущего времени в расписании (Time Indicator)**:
   - Динамическая горизонтальная линия с маркером текущего времени в `ScheduleWeekView`, обновляемая каждую минуту для быстрой ориентации в дне.
6. **E2E верификация**:
   - 56 E2E тестов в Docker (`make test-e2e`) пройдены успешно, чистая сборка фронтенда (`npm run lint && npm run build`, 0 ошибок).

## 📦 Реализованные компоненты

### 1. Серверная часть (Go & OpenAPI)
* **OpenAPI контракт** (`backend/api/openapi/api.yaml`):
  - Добавлены эндпоинты `/dashboard/summary`, `/analytics/forecast`, `/analytics/tags`.
  - Кодогенерация типов через `make oapi`.
* **Сервис Дашборда `DashboardService`** (`backend/internal/application/dashboard/`):
  - Метод `GetDashboardSummary`: уроки на сегодня, финансовый факт и прогноз месяца, суммарный долг учеников, запланированные часы недели.
* **Сервис аналитики `AnalyticsService`** (`backend/internal/application/analytics/`):
  - Метод `GetForecast`: агрегация будущих запланированных уроков, расчет выручки по ставкам учеников и прогнозируемой комиссии школ.
  - Метод `GetTagStats`: группировка проведенных уроков по тегам прикрепленных клиентов.
* **Сервис финансов `FinanceService`** (`backend/internal/application/finance/`):
  - Фильтрация `WHERE school_percent > 0` в партнерских взаиморасчетах.
* **HTTP Хэндлеры**:
  - `dashboard_handler.go`, расширение `analytics_handler.go` и `finance_handler.go`.
* **Тестирование**:
  - Юнит-тесты в `dashboard_handler_test.go`, `analytics_and_calendar_handler_test.go`, `finance_handler_test.go`.

### 2. Клиентская часть (React, TypeScript, Tailwind Liquid Glass)
* **Главный экран** (`frontend/src/pages/teacher/DashboardPage.tsx`):
  - `TodayLessonsWidget.tsx`: карточки сегодняшних занятий с прямыми ссылками на видеозвонки и статусами.
  - `FinanceSnapshotWidget.tsx`: сводный финансовый виджет месяца.
  - `QuickActionsWidget.tsx`: быстрые переходы в расписание, добавление учеников и бухгалтерию.
* **Вкладки Аналитики** (`frontend/src/pages/teacher/TeacherAnalyticsPage.tsx`):
  - Segmented Control переключатель «История» / «Прогноз».
  - Карточки прогноза нагрузки и ожидаемого дохода с разбивкой по форматам.
  - `AnalyticsTagsDistribution.tsx`: таблица доходности по категориям тегов.
* **Бухгалтерия**:
  - `PartnerSettlementsCard.tsx`: отображение только партнерских школ (`school_percent > 0`).
* **Календарь**:
  - `ScheduleWeekView.tsx`: динамический индикатор времени текущего дня.
