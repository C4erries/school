# Спринт 2.1.2: Полировка CRM, Карточки ученика и Формы урока

> Статус: ✅ **ЗАВЕРШЕН** (2026-10-05)

## Цель спринта
1. **Редактирование ученика на фронтенде**: добавить кнопку редактирования (карандаш) на карточку ученика в CRM, модалку с предзаполненными данными и отправку запроса `PATCH /api/v1/clients/{id}`.
2. **Формат занятия в создании и редактировании урока**: внедрить явный выбор формата (`individual` / `pair` / `group`), синхронизировать с типом проведения (оффлайн с кабинетом / онлайн с ссылкой) и списанием соответствующих абонементов.
3. **Исправление вёрстки тарифной сетки**: исключить некрасивый перенос звёздочки под словом «Индивидуально» на узких экранах и в колонках модалки.
4. **Обновление автотестов**: проверить сценарий редактирования клиента через API и фронтенд-валидацию.
