## Текущая фаза: 2 — Расписание, Кабинеты и Уроки 🔵

### Цель спринта
Реализовать назначение уроков преподавателем для закрепленных учеников, согласование учеником («Принять» / «Отклонить»), управление кабинетами школы и прикреплением учеников администратором, поддержку нахлёста занятий у одного преподавателя, защиту от коллизий кабинетов, фронтенд в эстетике Apple Liquid Glass и сквозные E2E автотесты.

### Definition of Done (DoD) Фазы 2
- [x] Администратор может создавать кабинеты школы и прикреплять учеников к преподавателям.
- [x] Преподаватель видит своих прикрепленных учеников и может назначить урок (онлайн или с выбором кабинета).
- [x] Система разрешает преподавателю ставить уроки внахлёст, но блокирует попытку занять один и тот же кабинет двумя разными преподавателями.

- [x] Администратор видит общее расписание школы с фильтрами по преподавателю и кабинету.

- [x] Фронтенд работает без ошибок TypeScript и линтера.

### Бэклог / Будущие улучшения
- [ ] **Отображение локации занятия (Кабинет / Онлайн)**: В календаре преподавателя (как в сетке, так и в списке уроков) и на карточках занятий ученика выводить явное название кабинета (с цветной точкой аудитории) или бейдж «Онлайн» со ссылкой.
- [ ] **Синхронизация API-роутов и честная обработка ошибок**:
  - Привести URL во фронтенде в точное соответствие с бэкендом: `/api/v1/teachers/students` (вместо `/teacher-students`), `/api/v1/lessons/{id}/cancel` (вместо `/no-show`).
  - Убрать «тихий» fallback в `localStorage` при ошибках API: показывать понятный toast/alert пользователю, если бэкенд возвращает ошибку (например, `STUDENT_NOT_ASSIGNED` или `CLASSROOM_COLLISION`).
- [ ] **Эндпоинт списка пользователей для Администратора (`GET /api/v1/users`)**: Реализовать на бэкенде получение реальных пользователей школы по ролям (`teacher`, `student`), чтобы администратор в реальном интерфейсе мог выбирать настоящих пользователей и прикреплять учеников к репетиторам.
- [ ] **Корректный учет таймзон в календаре**: Заменить строковое сравнение дат через `.startsWith(selectedDateStr)` на локальные компоненты даты браузера (`YYYY-MM-DD` в часовом поясе клиента), чтобы вечерние/ночные уроки не пропадали из текущего дня из-за сдвига UTC.
- [ ] **UX пустых состояний для нового преподавателя**: Если у репетитора ещё нет закреплённых учеников, в модалке «Назначить урок» отображать дружелюбный empty-state («У вас пока нет прикрепленных учеников. Обратитесь к администратору») вместо выбора несуществующих тестовых пользователей.
