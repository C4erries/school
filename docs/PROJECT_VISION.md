# School — Видение проекта

## Миссия

Умный помощник для онлайн/оффлайн школы и репетиторского центра: гибкое расписание занятий, учет оплат и взаиморасчетов, индивидуальные траектории обучения и удобная проверка домашних заданий с фото.

## Целевые пользователи

| Роль | Описание |
|------|----------|
| **Ученик (Student)** | Выбирает слоты, переносит занятия, изучает уроки, загружает фото домашних заданий |
| **Преподаватель (Teacher)** | Ведет расписание слотов, проводит уроки (онлайн/оффлайн), адаптирует программу под ученика, видит личный финансовый дашборд |
| **Ассистент (Assistant)** | Разгружает преподавателя: проверяет сданные фото ДЗ, дает обратную связь |
| **Владелец / Админ (Owner)** | Управляет ставками и комиссиями школы, видит сводный дашборд доходов и взаиморасчетов с преподавателями |

## Ключевые модули

### 📅 1. Расписание и бронирование занятий (Ядро MVP v1)
- Гибкая сетка свободных слотов преподавателя
- Онлайн-занятия (ссылки на созвоны) и оффлайн-занятия (кабинеты/локации)
- Бронирование занятий учениками
- Запросы на перенос и отмену занятий с учетом правил школы
- Фиксация статуса урока (проведено / отмена / неявка)

### 💰 2. Финансы и взаиморасчеты (Tutor Ledger)
- Учет стоимости занятий и баланса учеников
- Личный финансовый дашборд преподавателя (заработок, проведенные часы, долги учеников)
- Сводный дашборд владельца: выручка школы, расчет комиссий/процентов с преподавателей
- Фиксация ручных переводов (СБП, карта, нал) без лишней бюрократии

### 🎓 3. Курсы и адаптивные траектории обучения
- Базовые шаблоны курсов (модули, уроки, теория, задачи)
- Возможность кастомизировать программу под конкретного ученика (разные классы/уровни)
- Видео-материалы (MinIO) и файлы конспектов

### 📝 4. Задания и проверка фото-решений
- Загрузка пачки фотографий тетради (с превью и упорядочиванием)
- Очередь проверки для ассистентов и преподавателей
- Статусы: `submitted` → `in_review` → `approved` / `needs_revision`
- Комментарии и обратная связь

### 🤖 5. Интеграции и AI (Будущее)
- Синхронизация с Google Calendar
- Уведомления в Telegram
- AI-помощник по материалам курса для ученика

### 💬 Коммуникации
- Чат между учениками и преподавателями
- Уведомления (in-app, email, push)
- AI-чат ассистент (будущее)

### 🤖 AI (будущее)
- Чат-бот помощник по курсу
- Автопроверка простых заданий
- Рекомендации по обучению

### 🔐 Безопасность и доступ
- Аутентификация (JWT, refresh tokens)
- RBAC (Role-Based Access Control)
- OAuth2 (Google, etc.)

## Технологический стек

| Компонент | Технология |
|-----------|------------|
| Backend | Go |
| Frontend | React + TypeScript |
| БД | PostgreSQL |
| Кэш | Redis |
| Хранилище файлов | MinIO (S3-compatible) |
| Контейнеризация | Docker + Docker Compose |
| Reverse proxy | Nginx |
| Миграции БД | goose / golang-migrate |
| API | REST (OpenAPI) → gRPC (по мере роста) |

## Принципы

- **Размеренность**: делаем поэтапно, каждый этап — рабочий продукт
- **12-Factor**: без фанатизма, но конфиг через env, логи в stdout, stateless сервисы
- **DDD в Go**: стиль определим отдельно, но доменная логика отделена от инфраструктуры
- **Документация**: решения фиксируем, AI-агенты должны понимать контекст
