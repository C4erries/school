# School — Видение проекта

## Миссия

Платформа для онлайн/оффлайн школы: видео-уроки, проверка заданий, расписание, финансы, AI-ассистент — всё в одном месте.

## Целевые пользователи

| Роль | Описание |
|------|----------|
| **Ученик (Student)** | Смотрит уроки, загружает домашки, общается с преподавателями |
| **Преподаватель (Teacher)** | Создаёт курсы, проверяет задания, ведёт занятия |
| **Ассистент (Assistant)** | Помогает проверять задания, модерирует |
| **Админ (Admin)** | Управляет школой, финансами, пользователями |

## Ключевые фичи (полная картина)

### 🎓 Обучение
- Курсы с модулями и уроками
- Видео-контент (загрузка, стриминг, транскодинг)
- Материалы к урокам (PDF, файлы)
- Прогресс ученика

### 📝 Задания и проверка
- Загрузка домашних заданий (фото, файлы, текст)
- Система проверки для преподавателей/ассистентов
- Обратная связь, оценки, комментарии
- Статусы: сдано → на проверке → проверено / на доработку

### 📅 Расписание и встречи
- Календарь занятий (онлайн и оффлайн)
- Интеграция с Google Calendar
- Бронирование слотов
- Напоминания (email, push)

### 💰 Финансы
- Учёт оплат за занятия
- Начисления преподавателям
- История транзакций
- Интеграция с платёжными системами

### 💬 Коммуникации
- Чат между учениками и преподавателями
- Уведомления (in-app, email, push)
- AI-чат ассистент (будущее)

### 🤖 AI (будущее)
- Чат-бот помощник по курсу
- Автопроверка простых заданий
- Рекомендации по обучению

### 🔐 Безопасность и доступ
- Аутентификация (JWT, refresh tokens)
- RBAC (Role-Based Access Control)
- OAuth2 (Google, etc.)

## Технологический стек

| Компонент | Технология |
|-----------|------------|
| Backend | Go |
| Frontend | React + TypeScript |
| БД | PostgreSQL |
| Кэш | Redis |
| Хранилище файлов | MinIO (S3-compatible) |
| Контейнеризация | Docker + Docker Compose |
| Reverse proxy | Nginx |
| Миграции БД | goose / golang-migrate |
| API | REST (OpenAPI) → gRPC (по мере роста) |

## Принципы

- **Размеренность**: делаем поэтапно, каждый этап — рабочий продукт
- **12-Factor**: без фанатизма, но конфиг через env, логи в stdout, stateless сервисы
- **DDD в Go**: стиль определим отдельно, но доменная логика отделена от инфраструктуры
- **Документация**: решения фиксируем, AI-агенты должны понимать контекст
